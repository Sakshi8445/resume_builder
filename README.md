# resume_builder
This is a full-featured, interactive Resume Builder application designed to simplify the process of creating professional CVs. The platform allows users to input their personal details, work experience, education, and skills through an intuitive step-by-step form. It features a real-time preview system so users can see changes instantly and offers multiple modern, recruiter-friendly templates. Once completed, the resume can be seamlessly exported as a high-quality, ATS-friendly PDF.

Key Features:
Live Preview: Dynamic rendering that updates the resume layout instantly as you type.Customizable 

Templates: Switch between multiple professional layouts and color themes with a single click.

Interactive Forms: Structured sections for easy data entry (Experience, Education, Projects, Skills, and Social Links).

One-Click Export: High-quality PDF generation with optimized formatting for printing and ATS scanning.

Tech Stack: Built using [React.js / HTML5 / CSS3] for the frontend, [Node.js / Express] for the backend, and [MongoDB] for data storage.
